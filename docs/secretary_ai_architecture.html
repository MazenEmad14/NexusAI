    subgraph KB ["🧠 Knowledge Base Search"]

    end

    FI{"📊 Found Relevant\nInformation?\nscore > threshold"}:::decision

    subgraph GEN ["🤖 Answer Generation"]
        direction TB
        CTX["📄 Build Context\nRetrieved Chunks"]:::process
        PROMPT["✍️ Create Prompt\nTemplate + Context + Query"]:::process
        LLM["🧠 LLM Generation\nGenerate Answer"]:::llm
    end

    subgraph GMAIL ["📧 Gmail Search"]
        direction TB
        GQUERY["🔍 Build Gmail Query\nKeywords Extraction"]:::process
        GAPI["📨 Gmail API Call\nSearch Messages"]:::gmail
        GPARSE["📋 Parse Results\nExtract Fields"]:::process
    end

    FE{"📨 Found\nRelevant Emails?"}:::decision

    subgraph SUMMARIZE ["📋 Email Summarization"]
        direction TB
        EXTRACT["📝 Extract Details\nSender, Subject, Date"]:::process
        SUM["🤖 Summarize Content\nLLM Summarization"]:::llm
    end

    NIF["❌ No Information Found\nApologetic Response"]:::error

    OUTPUT["📝 → Format Output Node"]:::output

    INPUT --> EMBED --> SEARCH --> RANK --> FI

    FI -->|"✅ YES — Documents Found"| CTX --> PROMPT --> LLM --> OUTPUT
    FI -->|"❌ NO — Not in KB"| GQUERY --> GAPI --> GPARSE --> FE

    FE -->|"✅ YES — Emails Found"| EXTRACT --> SUM --> OUTPUT
    FE -->|"❌ NO — Nothing Found"| NIF --> OUTPUT

LangGraph State

State Object Schema

The shared state object passed between all LangGraph nodes.

📦
AgentState
TypedDict — LangGraph State Schema
state.py 
# LangGraph State Object
from typing import TypedDict, List, Dict, Optional

class AgentState(TypedDict):
    # User input
    query: str                    # Raw user query

    # Classification
    request_type: str             # "retrieval" | "action"
    action_type: str              # "send_email" | "calendar" | "reminder"

    # Retrieval results
    knowledge_results: List[Dict]  # RAG search results
    emails: List[Dict]            # Gmail search results

    # Action details
    action_details: Dict          # Extracted action params

    # Output
    result: str                   # Final formatted response
    status: str                   # "success" | "error"
    metadata: Dict               # Additional context

Technology Stack

Core Technologies

The building blocks powering the Secretary AI system.

🧠

LangGraph

Orchestration framework for the multi-step AI agent workflow with state management.

⚡

FastAPI

High-performance async API framework for receiving user queries and serving responses.

🤖

LLM (GPT/Gemini)

Large Language Model for query classification, answer generation, and summarization.

🔎

FAISS / Chroma

Vector database for similarity search and semantic retrieval in the RAG pipeline.

🗄️

MongoDB

NoSQL database for storing queries, emails, meetings, reminders, and document chunks.

📧

Gmail API

Google Gmail API for searching, reading, and sending emails via OAuth2.

📅

Google Calendar

Calendar API for creating events, managing schedules, and setting up meetings.

💬

WhatsApp Format

Clean, emoji-rich response formatting for user-friendly output presentation.
